# Описание изображений простыми дескрипторами и распознавание объектов

MATLAB-скрипт для описания изображений с помощью простых статистических дескрипторов и распознавания объектов на основе сравнения с эталоном (классификация по ближайшему центру кластера).

## Наборы данных

- **notMNIST** — изображения букв английского алфавита ([kaggle.com](https://www.kaggle.com))
- **Fashion MNIST PNG** — изображения одежды ([kaggle.com](https://www.kaggle.com))

Изображения должны быть организованы в структуру каталогов, где имя папки соответствует метке класса (используется `imageDatastore` с параметром `LabelSource="foldernames"`).

## Дескрипторы

Для каждого бинаризованного изображения (`imbinarize(I,'global')`) вычисляются проекции пикселей:

- `X = sum(I,1)` — сумма значений пикселей по столбцам;
- `Y = sum(I,2)` — сумма значений пикселей по строкам.

На их основе формируются четыре варианта дескрипторов:

| Дескриптор | Размерность | Описание |
|------------|-------------|----------|
| `D_1` | 56 | Конкатенация `[X, Y']` |
| `D_2` | 28 | Разность `X - Y'` |
| `D_3` | 28 | Модуль разности `abs(X - Y')` |
| `D_4` | 4 | Статистики по `D_1`: mean, std, mode, median |

## Алгоритм работы

1. **Загрузка изображений и вычисление дескрипторов** — параллельная обработка файлов (`parfor`), чтение через `imageDatastore`.
2. **Вычисление центров кластеров** — для каждого класса усредняются дескрипторы обучающего набора.
3. **Распознавание тестовых изображений** — для каждого объекта находится кластер с минимальным средним модулем разности дескрипторов (`predict_images`).
4. **Оценка точности классификации** — выводятся матрицы путаниц (`confusionchart`, column-normalized) и средняя точность для каждого дескриптора.

## Требования

- MATLAB с Toolbox: Image Processing Toolbox, Statistics and Machine Learning Toolbox, Parallel Computing Toolbox (для `parfor`).

## Использование

1. Скачайте один из наборов данных (notMNIST или Fashion MNIST PNG) и распакуйте его.
2. В файле `Image_description_and_recognition.m` укажите путь к данным в вызове `imageDatastore(...)`:
   ```matlab
   imdDir = imageDatastore('путь/к/данным/train', "IncludeSubfolders", true, "LabelSource", "foldernames");
   ```
   Для тестирования раскомментируйте строку с путём к папке `test`.
3. Запустите скрипт `Image_description_and_recognition.m`.
