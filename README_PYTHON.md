# Описание изображений простыми дескрипторами и распознавание объектов (Python)

Python-скрипт `Image_description_and_recognition.py` — аналог MATLAB-программы
`Image_description_and_recognition.m` для описания изображений с помощью простых
статистических дескрипторов и распознавания объектов на основе сравнения с эталоном
(классификация по ближайшему центру кластера).

## Наборы данных

- **notMNIST** — изображения букв английского алфавита ([kaggle.com](https://www.kaggle.com))
- **Fashion MNIST PNG** — изображения одежды ([kaggle.com](https://www.kaggle.com))

Изображения должны быть организованы в структуру каталогов, где имя папки
соответствует метке класса (аналог `imageDatastore` с параметрами
`IncludeSubfolders=true`, `LabelSource="foldernames"`). Поддерживаются файлы
`.png`, `.jpg`, `.jpeg`, `.bmp`, `.tif`, `.tiff`.

## Дескрипторы

Для каждого бинаризованного изображения (пороговая бинаризация по глобальному
порогу Оцу — аналог `imbinarize(I,'global')`) вычисляются проекции пикселей:

- `X = sum(I, axis=0)` — сумма значений пикселей по столбцам;
- `Y = sum(I, axis=1)` — сумма значений пикселей по строкам.

Проекции приводятся к фиксированной длине 28 (обрезка/дополнение нулями), после
чего формируются четыре варианта дескрипторов:

| Дескриптор | Размерность | Описание |
|------------|-------------|----------|
| `D_1` | 56 | Конкатенация `[X, Y]` |
| `D_2` | 28 | Разность `X - Y` |
| `D_3` | 28 | Модуль разности `abs(X - Y)` |
| `D_4` | 4 | Статистики по `D_1`: mean, std, mode, median |

## Алгоритм работы

1. **Загрузка изображений и вычисление дескрипторов** — рекурсивный поиск файлов
   (`find_image_files`), параллельная обработка через `joblib.Parallel`
   (аналог `parfor`).
2. **Вычисление центров кластеров** — для каждого класса усредняются дескрипторы
   обучающего набора.
3. **Распознавание тестовых изображений** — для каждого объекта находится кластер
   с минимальным средним модулем разности дескрипторов (`predict_images`).
4. **Оценка точности классификации** — печатается средняя точность для каждого
   дескриптора и выводятся матрицы путаниц (`sklearn.metrics.ConfusionMatrixDisplay`,
   нормализация по столбцам).

## Требования

Python >= 3.8 и пакеты:

- `numpy`
- `Pillow` (PIL)
- `joblib`
- `scikit-learn`
- `matplotlib`

Установка зависимостей:

```bash
pip install numpy pillow joblib scikit-learn matplotlib
```

## Использование

1. Скачайте один из наборов данных (notMNIST или Fashion MNIST PNG) и распакуйте его.
2. Укажите пути к данным в блоке запуска скрипта (или передайте их в `main()`):
   ```python
   if __name__ == '__main__':
       TRAIN_DIR = r'путь/к/данным/train'
       TEST_DIR  = r'путь/к/данным/test'   # необязательно, по умолчанию — train
       main(TRAIN_DIR, TEST_DIR)
   ```
3. Запустите скрипт:
   ```bash
   python Image_description_and_recognition.py
   ```

Аргументы функции `main(train_dir, test_dir=None, n_jobs=-1)`:

- `train_dir` — каталог обучающих изображений (подпапки = классы);
- `test_dir` — каталог тестовых изображений; если `None` или совпадает с
  `train_dir`, обучение и тестирование выполняются на одном наборе (как в исходной
  MATLAB-версии);
- `n_jobs` — число параллельных процессов (`-1` — использовать все ядра).

## Отличия от MATLAB-версии

| MATLAB | Python-аналог |
|--------|---------------|
| `imageDatastore(..., LabelSource="foldernames")` | `find_image_files()` — обход каталога `os.walk` |
| `imbinarize(I, 'global')` | `imbinarize_global()` — порог Оцу на гистограмме |
| `parfor` | `joblib.Parallel(n_jobs=-1)` |
| `confusionchart(..., 'ColumnNormalization', true)` | `sklearn.metrics.confusion_matrix` + `ConfusionMatrixDisplay` |
